Полная документация на [GitHub Pages](https://github.com/ggabrann/SpaceCoreIskra-vOmega/pages).

## Вклад и рабочий процесс
1. Прочитайте актуальные соглашения в [`AGENTS.md`](AGENTS.md) и уточните метрики ∆/D/Ω/Λ для задачи.
2. Создайте рабочую ветку, выполните `make setup` (один раз) и убедитесь, что базовые проверки `make lint` и `make test` проходят локально.
3. Перед публикацией изменений прогоните полный пакет `make ci` — он включает проверки Unicode/ASCII, схем журналов и безопасность veil.
4. Обновляйте журналы (`JOURNAL.jsonl`, `SHADOW_JOURNAL.jsonl`) и релизные артефакты (`DIST_MANIFEST.json`, `DIST_NOTE.md`) при изменении пользовательского поведения.
5. Подготовьте PR с блоком `#ANCHOR`, описанием «что было / что стало», перечнем тестов и подтверждением соответствия DoD.
