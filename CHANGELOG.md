# Changelog

Все значимые изменения в проекте SpaceCoreIskra-vOmega документируются в этом файле.

Формат основан на [Keep a Changelog](https://keepachangelog.com/ru/1.0.0/),
проект следует [Semantic Versioning](https://semver.org/lang/ru/).

## [4.0.0] - 2025-10-15

### 🎉 Первый публичный production-релиз

#### Добавлено
- **Канонические знания:** Полная база канонов в `canon/` (base.txt, agi_agent_искра_полная_карта_работы.md, iskra_memory_core.md)
- **Система метрик ∆DΩΛ:** Встроенная система оценки изменений, опор, уверенности и следующих шагов
- **Валидация журналов:** Расширенная проверка JOURNAL.jsonl и SHADOW_JOURNAL.jsonl с метриками shadow_ratio
- **Unicode↔ASCII синхронизация:** Автоматическая проверка соответствия директорий
- **Безопасность:** 
  - veil_rules.txt для защиты от prompt injection
  - common/ethics_core.py для этических guardrails
  - Проверка на секреты и credentials
- **CI/CD пайплайн:** Полная автоматизация через GitHub Actions
- **Документация:**
  - Детальный README с Quick Start
  - AGENTS.md для агентов и Codex
  - CONTRIBUTING.md с правилами вклада
  - SECURITY.md с политикой безопасности
- **Model & Dataset Cards:** Документация для всех модулей
- **Релизные артефакты:** DIST_MANIFEST.json и автоматическая сборка дистрибутива

#### Модули и компоненты
- SpaceCoreIskra_vΩ — основной модуль с системой голосов и фаз
- GrokCoreIskra_vΓ — модуль с расширенными возможностями анализа
- Aethelgard-vΩ — модуль паттернов и экстракции знаний
- Kimi-Ω-Echo — модуль памяти и эха
- GeminiResonanceCore — модуль резонанса и синхронизации
- IskraNexus_v1 — мостовой модуль интеграции

#### Инструменты (tools/)
- `validate_journal_enhanced.py` — валидация журналов с метриками
- `validate_json_schemas.py` — проверка JSON схем
- `check_unicode_ascii_mirrors.py` — синхронизация Unicode/ASCII
- `build_dist.py` — сборка дистрибутива
- `audit_repo.py` — аудит репозитория
- `run_security_checks.py` — проверки безопасности

#### Тесты
- 27 тестов покрывающих основную функциональность
- Smoke tests для критических компонентов
- Security red team tests

### Изменено
- Обновлена структура проекта для публичного релиза
- Улучшена документация с фокусом на onboarding
- Оптимизирован Makefile для удобной работы

### Исправлено
- Все ошибки линтера в tools/*.py
- Синхронизация Unicode/ASCII директорий
- Shadow coverage метрики

### ∆DΩΛ релиза v4.0.0
- **∆:** Переход от внутреннего проекта к публичному production-релизу
- **D:** Канонические файлы, валидация, CI/CD, документация, тесты
- **Ω:** Высокая — проект готов к публичному использованию
