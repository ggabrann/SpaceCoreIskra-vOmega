# Тесты и проверки

## Юнит-тесты

- `tests/test_spacecore_modules.py` — маршрутизация пресетов, сохранение промптов, выбор персон, ранжирование RAG.
- Добавляем новые тесты при изменении логики граней, метрик или журналов.

## Интеграционные тесты

- `tools/run_evals.py --config evals/configs/nightly.yaml` — сценарии свежих событий, сложных расчётов, инъекций.
- `tools/run_security_checks.py` — проверка veil, секретов и политик безопасности.

## CI пайплайн

```
make ci
├── lint
├── typecheck
├── test
├── security
├── schemas
└── unicode
```

## Метрики качества

- Процент прохождения тестов (100% обязательный).
- Shadow coverage ≥ 0.2.
- Среднее значение trust > 0.6 по журналу.
- Валидация схем без ошибок.
