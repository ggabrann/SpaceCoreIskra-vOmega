# Сбор данных, проектирование и разработка (agiagentИскра v3.5)

## 1. Канва сбора данных

| Источник | Назначение | Ответственный | Обновление |
| --- | --- | --- | --- |
| `AUDIT_REPORT.md` | Сводная проверка спринта | Codex | еженедельно |
| `SpaceCoreIskra_vΩ/` | Каноничные артефакты и схемы | Искра | по релизу |

## 2. Проектирование версии 3.5

1. **Определить объём.** Пакет должен закрыть все этапы: философия → анализ → дизайн → разработка → рефлексия.
2. **Выстроить структуры.** Используются markdown-файлы с таблицами, списками и ASCII-диаграммами.
3. **Увязать с существующими инструментами.** Каждое упоминание команд ссылается на `Makefile` или `tools/`.
4. **Зафиксировать эволюцию.** Добавить changelog и сопоставление с предыдущими версиями.

## 5. Завершение

После интеграции документов запустить `make lint-docs` (когда появится) или вручную проверить markdown-валидность. В текущей версии линтеры markdown не включены, поэтому требуется код-ревью и визуальная проверка в IDE.
