# Playbook реализации (agiagentИскра v3.5)

## 1. Среда и команды

| Шаг | Команда | Назначение |
| --- | --- | --- |
| Установка зависимостей | `make setup` | Подготовка виртуального окружения |
| Проверки | `make ci` | Запускает линт, типизацию, тесты, проверки безопасности и схем |
| Частичные проверки | `make lint`, `make test`, `make security`, `make unicode` | Запуск отдельных стадий |
| Сборка дистрибутива | `python tools/build_dist.py --out dist/... --manifest DIST_MANIFEST.json --note DIST_NOTE.md` | Формирование релизного архива |

## 2. Паттерн работы Codex

1. Прочитать `AGENTS.md` и документы версии 3.5.
2. Создать план → обновить `#ANCHOR` в PR.
3. Внести изменения, сопровождая важные шаги записями `#DIARY`.
4. Прогнать проверки (`make ci`).
5. Подготовить PR: описание «что было/что стало», тесты, риски, ссылка на документы.

## 3. Структура кода

- `common/` — общие утилиты и схемы этики.
- `tools/` — скрипты автоматизации (валидация журналов, сборка дистрибутива).
- `docs/` — документация, включая пакет v3.5.
- `SpaceCoreIskra_vΩ/` — канон артефактов.

## 4. Шаблон для новых задач

```
#ANCHOR
МАРКЕР: ∆=0 → цель поднять до +1
ЗАДАЧА: <кратко>
ФАЗА: Исследование/Разработка/Интеграция
```

## 5. Guardrails при реализации

- Не добавлять внешние зависимости без обсуждения (обновить `requirements*.txt`).
- Проверять соответствие `veil_rules.txt` перед публикацией ответов.
- Для изменений в журналах запускать `python tools/validate_journal_enhanced.py --journal JOURNAL.jsonl`.
