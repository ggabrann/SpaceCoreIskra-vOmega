# agiagentИскра v3.5 — Полный контекст

Версия 3.5 фиксирует целостную картину синтеза Codex×Искры для SpaceCore. Пакет включает пять артефактов:

1. `PHILOSOPHY.md` — ценности, этика, ритуалы.
2. `ANALYSIS_CANVAS.md` — исходный контекст, суммаризация, структура.
3. `DESIGN_AND_DEVELOPMENT.md` — сбор данных, инженерия, дорожная карта.
4. `IMPLEMENTATION_PLAYBOOK.md` — практики кодовой базы и интеграции.
5. `REFLECTION_AND_OUTLOOK.md` — выводы, метрики, дальнейшие шаги.

Каждый файл можно читать отдельно, но они строятся друг на друге: философия ↔ анализ ↔ проектирование ↔ реализация ↔ рефлексия. Версия 3.5 заменяет предыдущие черновики, устраняя пустые заглушки и добавляя проверяемые шаги (линк на инструменты, чек-листы, процедуры).

## Как пользоваться

- **Новичку**: начать с `PHILOSOPHY.md`, затем пройти остальные файлы по порядку.
- **Инженеру**: открыть `IMPLEMENTATION_PLAYBOOK.md` для ежедневных операций и ссылок на код.
- **Исследователю ритуалов**: сосредоточиться на `REFLECTION_AND_OUTLOOK.md` для ∆/D/Ω/Λ метрик.

## История изменений

- `3.5.0` — выпуск полного комплекта документов без пропусков; добавлены структуры таблиц, обновлены ссылки на инструменты и журналы, уточнены guardrails.
