# Канон-файлы

Эта секция предназначена для артефактов канона «как есть». Добавляйте файлы и описания — они автоматически появятся в навигации MkDocs.

- Сохраняйте оригинальные названия и структуры каталогов.
- Для крупных вложений (>25 МБ) храните ссылки или дополнительные инструкции.
- Обновляйте Model Card после загрузки новых материалов, чтобы зафиксировать контрольные суммы.
