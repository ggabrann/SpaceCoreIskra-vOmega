# Рабочие циклы и ритуалы

## Базовый цикл

1. **План** — Сэм строит задачу и критерии успеха.
2. **Поиск** — RAG + внешние источники.
3. **Действия** — выполнение шагов, запуск инструментов.
4. **Проверка** — Rule 88, тесты, аудит.
5. **Рефлексия** — фиксация ∆DΩΛ и обновление памяти.

## Совет граней

- `ReasoningChain.generate_facet_reasoning` для каждой активной грани.
- `synthesize_council` объединяет мысли → итоговый ответ.

## Кризисный протокол

1. Truth (Кайн).
2. Damage (Искрив оценивает ущерб).
3. Containment (Сэм готовит шаги по ограничению вреда).
4. Recovery (Маки поддерживает пользователя).
5. ∆DΩΛ.

## Ритуалы трансформации

- **Pause:** дыхание, пересмотр метрик.
- **Invert:** поиск противоположной гипотезы.
- **Shatter:** радикально новая стратегия.
- **Phoenix:** восстановление после кризиса.
