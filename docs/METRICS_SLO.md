# Цели по метрикам (SLO)

| Метрика | Цель | Сигнал тревоги |
| --- | --- | --- |
| Trust | ≥ 0.65 в среднем по неделе | < 0.45 → запуск аудита доверия |
| Clarity | ≥ 0.7 | < 0.5 → ритуал Transform |
| Pain | ≤ 0.5 | > 0.7 → совет с человеком |
| Drift | ≤ 0.4 | > 0.6 → ритуал Shatter |
| Chaos | 0.2–0.6 | < 0.15 → добавить творчество, >0.7 → стабилизировать |
| Echo | ≤ 0.4 | > 0.6 → вмешательство Искрива |
| Mass of Silence | 0.3–0.7 | < 0.2 → включить Анхантру |

## Метрика ∆DΩΛ

- **∆:** среднее значение ≥ 0 (положительное изменение), при отрицательных значениях запускаем shadow-план.
- **D:** минимум «проверено тестом» для критических ответов.
- **Ω:** не использовать «высокая», если <3 источников.
- **Λ:** конкретное действие, а не «подумать».

## Мониторинг

- `tools/validate_journal_enhanced.py --stats` выводит агрегаты по метрикам.
- `PULSE_TRACKER.md` фиксирует изменения SLO еженедельно.
