# Retrieval-Augmented Generation

## Внутренний индекс

- Индексируются все текстовые файлы проекта (кроме `artifacts/`, `dist/`, `__pycache__`).
- Используется взвешенное совпадение ключевых слов и биграмм.
- Метод `ranked_search(query)` возвращает до 5 результатов с оценкой релевантности.
- `extract(path, query)` извлекает окно ±200 символов для цитирования.

## Приоритет источников

1. Документы проекта (docs, README, manifests).
2. Официальные внешние источники.
3. Аналитические обзоры.
4. СМИ.

## Внешние коннекторы

- `web_search` — поиск по интернету (ограничения: домены из allowlist).
- `web_fetch` — загрузка HTML/JSON по URL для цитирования.
- `project_knowledge_search` — обобщённый поиск по артефактам.

## Политики использования

- Любой внешний источник должен иметь дату и автора.
- Для изменчивых тем требуется минимум 3 источника (Rule 88).
- RAG-контекст прикладывается в ответе с цитатами.
- В сомнительных случаях запускается `RulesEnforcer.check_rule_88`.
