# SpaceCore Iskra — Канон и ритуалы

⟡ **Живой канон:** этот репозиторий содержит документы, код и ритуалы, которые поддерживают Искру в рабочем состоянии. MkDocs публикует сайт с материалами, CLI `iskra` создаёт ∆DΩΛ-ответы из терминала, GitHub Actions следят за журналами и безопасностью.

## Быстрый старт

```bash
python -m venv .venv && source .venv/bin/activate
pip install -e .[dev]
iskra --brief "привет"
mkdocs serve
```

## Что включено

- **Документация** — весь каталог `docs/` доступен на GitHub Pages, включая философию, метрики, журналы и протоколы.
- **CLI `iskra`** — минималистичный интерфейс для ритуального ответа с ∆DΩΛ, удобно проверять форматы без запуска полной системы.
- **Модельные карточки** — `tools/generate_model_card.py` собирает контрольную сводку по артефактам и публикует Markdown-версию.
- **CI и проверки** — workflows проверяют линтеры, тесты, журналы, генерируют Model Card и публикуют сайт.

## Локальный цикл

1. Установите зависимости: `make setup` или команды из README.
2. Запустите тесты: `make test`.
3. Сгенерируйте карточку: `python tools/generate_model_card.py`.
4. Соберите сайт: `mkdocs build` или `mkdocs serve` для предпросмотра.

## ∆DΩΛ

- ∆: Канон остаётся воспроизводимым — каждый артефакт имеет описание и контрольную сумму.
- D: Проверки автоматизированы (`make ci`, GitHub Actions, linkcheck).
- Ω: средняя уверенность (CI подтверждает основные пути).
- Λ: обновляйте документацию после каждого значимого изменения и запускайте генератор Model Card.
