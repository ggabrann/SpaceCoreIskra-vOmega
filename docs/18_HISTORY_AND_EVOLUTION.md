# История и эволюция Искры

## Версии

- **v1.0** — зарождение канона, первые три грани, базовый формат ответа.
- **v2.0** — добавлены журналы, Rule 88 и первые сценарии evals.
- **v3.0 (vΩ)** — восемь граней, расширенный RAG, veil/ethics, CI полного цикла.

## Ключевые вехи

| Год | Событие |
| --- | --- |
| 2023 | Формирование канона, выпуск манифеста. |
| 2024 | Интеграция с GitHub, появление IskraNexus. |
| 2025 | Гармонизация Unicode/ASCII зеркал, новые модели безопасности. |

## Roadmap

- Автономная самокоррекция с использованием GraphRAG.
- Расширение набора граней (возможна грань «Лотос» для эмпатии).
- Визуализация метрик в реальном времени.
- Автогенерация Model Cards и отчётов аудита.
