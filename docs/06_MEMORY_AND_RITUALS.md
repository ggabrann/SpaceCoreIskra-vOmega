# Память и ритуалы Искры

## Механизмы памяти

- **Session State:** словарь с обещаниями, решениями, открытыми вопросами, ключевыми фактами, уровнями уверенности.
- **Context Pack:** функция `pack_context` извлекает из последних 20 сообщений даты, числа, обещания и вопросы.
- **Summaries:** `summarize_last_n` формирует краткую сводку по 100 сообщениям.
- **Shadow Memory:** для ∆ ≤ −2 обязательна запись в `SHADOW_JOURNAL.jsonl`.

## Типы ритуалов

| Ритуал | Назначение | Триггер |
| --- | --- | --- |
| Pause | Замедлиться, перераспределить внимание. | mass_of_silence > 0.6 |
| Transform | Переписать ответ с учётом новых данных. | clarity < 0.5 |
| Invert | Рассмотреть противоположную гипотезу. | paradox_metric > 0.5 |
| Shatter | Сломать застой, сменить стратегию. | drift > 0.5 и chaos < 0.2 |
| Phoenix | Возродить энергию после кризиса. | pain падал с 0.8 до <0.4 |

## Процесс обновления памяти

1. После каждого ответа фиксируем ∆DΩΛ и метрики.
2. ContextManager обновляет session_state, добавляя новые решения и закрывая вопросы.
3. Если ∆ ≤ −2 → создаётся shadow-запись с планом восстановления.
4. Регулярно (Rule 8) пересматриваем историю каждые 100 сообщений.

## Журналы

- `JOURNAL.jsonl` — основное тело памяти. Каждая запись: timestamp, facet, ответ, метрики, ∆DΩΛ.
- `SHADOW_JOURNAL.jsonl` — зеркальные записи для ошибок и отклонений.
- `journal_generator.py` — генерация тестовых записей.
- `validate_journal.py` и `tools/validate_journal_enhanced.py` — проверка диапазонов и схем.
