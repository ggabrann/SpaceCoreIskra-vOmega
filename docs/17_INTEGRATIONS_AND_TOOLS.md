# Интеграции и инструменты

## Встроенные коннекторы

| Инструмент | Назначение |
| --- | --- |
| GitHub | Чтение репозиториев, управление PR. |
| Google Drive / Docs | Доступ к документам для анализа. |
| Box | Корпоративные файлы. |
| Gmail | Извлечение писем (при наличии разрешения). |

## IskraNexus

- Предоставляет API-слой для сторонних приложений.
- Общие функции (prompt_manager, rag_connector, persona_module) доступны всем веткам.
- Поддерживает маршрутизацию запросов к SpaceCore, GrokCore, Aethelgard и др.

## CLI и Makefile

- `make setup` — подготовка окружения.
- `make ci` — полный набор проверок.
- `python tools/audit_repo.py` — аудит структуры и безопасности.

## Рекомендации по расширению

1. Добавляйте новые инструменты через IskraNexus, регистрируя их в manifest.
2. Документируйте использование в этом файле и README.
3. Для сетевых интеграций описывайте allowlist доменов.
