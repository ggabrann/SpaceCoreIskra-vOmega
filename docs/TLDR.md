# TL;DR (Краткое резюме)

Проект **ТЕ́ЛОС-Δ** — это архитектура Порогового Метасапиенса, основанная на:

1.  **Ядре (Core)**: Гибрид Attention/SSM (Mamba-2) с режимами мышления (TTiC) вместо одной "модели".
2.  **Памяти (Memory)**: **GraphRAG** (Графовое знание) поверх **pgvector** (Векторный индекс) для строгой атрибуции.
3.  **Оркестрации (Orchestration)**: **LangGraph** для многошаговых потоков и **Дебатов** (MoA) с **Судьей** (Canon Review).
4.  **Управлении (Governance)**: Метрики (CD-Index, Canon Review) и **Комплаенс** (EU AI Act, GPAI Code) для контролируемой эволюции.

## Фокус Фазы-0 (1-3 недели):
*   Развертывание **vLLM** + 7-8B LLM.
*   Базовый **RAG** на **pgvector**.
*   Первичные метрики (CD-Index v0).
*   Релиз-гейт **Canon Review**.

## Главные принципы:
*   **Строгая атрибуция**: Каждый вывод связан с фрагментом источника.
*   **Воспроизводимость**: Фиксация версий и метрик.
*   **Отказ от "героических" решений**: Использование комбинации подходов, а не одной "серебряной пули".
