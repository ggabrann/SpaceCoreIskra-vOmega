# Полная политика безопасности

## Стратегия

- **OWASP Top-10 for LLM (2025):** покрыты через veil, rules, secret scanning.
- **PII:** данные пользователей не сохраняются, чувствительные фрагменты анонимизируются.
- **EU AI Act:** ведутся журналы решений, хранится документация по рискам.

## Guardrails

| Компонент | Назначение |
| --- | --- |
| `veil_rules.txt` | Список запрещённых паттернов и атак. |
| `common/ethics_core.py` | Политики этики и фильтрации. |
| `tools/audit_repo.py` | Автоматический аудит репозитория. |
| `tools/run_security_checks.py` | Сборка проверок безопасности. |

## Процедуры

1. Перед релизом запускать `make security` и `python tools/audit_repo.py`.
2. Любые изменения в veil/ethics документировать в `CHANGELOG.md` и shadow-журнале.
3. Подозрительные запросы переводить в режим «Совет граней» для коллективной проверки.
4. Инциденты фиксировать в `SECURITY.md` (раздел Responsible Disclosure).
