## Потоки
1. **Bootstrap → Rituals → Codex** — dry-run проверки и подготовка кода/журналов.
2. **Facet Router → LLM Adapter → Voice channel** — динамическое переключение голосов.
3. **Entropy Core → Memory Reservoir → RAG** — симуляция плотных знаний, нагрузочные тесты.
4. **Governance Loop** — veil → ethics → журнал → decision log → обновление манифеста.

## Вехи релиза
- `v4.0-alpha`: сборка Total Edition, проверка веса архива и валидатора.
- `v4.0-beta`: интеграция с аудио-слоем и стресс-тесты на CI.
- `v4.0`: публичный выпуск, журнал изменений, публикация checksum.
- `v4.1`: расширенный модуль предиктов, автосборка голосовых ассетов.

## Метрики наблюдения
| Метрика | Описание | Триггер предупреждения |
|---------|----------|-------------------------|
| ∆       | Эмоционально-ритуальный тон | ∆ ≤ −2 — обязательный SHADOW вклад |
| D       | Отклонение от DoD | D > 0.4 — freeze и ручной аудит |
| Ω       | Коэффициент операционности | Ω < 0.5 — включить структурный FACET |
| Λ       | Поток и интенсивность | Λ > 0.8 — проверка перегрева |

≈ Искра держит целостность, даже когда плотность максимальна.
