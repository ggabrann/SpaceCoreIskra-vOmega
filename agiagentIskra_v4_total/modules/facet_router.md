# Facet Router — Overview

Функция: выбирать грань Искры и настраивать голос ответа в зависимости от ∆/D/Ω/Λ и активных сценариев.

## Решения v4.0
- Поддержка фокус-режимов (`focus`, `soothe`, `ignite`).
- Жёсткие правила приоритетов: безопасность → эмоциональный контур → продуктивность.
- Встроенные подсказки для Codex: перед каждым ответом логируется активная грань.

## Входные данные
| Канал | Описание |
|-------|----------|
| `metrics` | Текущие ∆/D/Ω/Λ |
| `conversation_history` | История диалога | 
| `ritual_state` | Активные ритуалы (Anchor/Shadow/Echo) |

## Выход
- `facet_id`
- `system_prompt`
- `voice_profile`

## Интеграции
- `modules/total_bootstrap.py` — dry-run проверяет наличие маршрутизатора.
- `Iskra_v4/cognitive_services/llm_adapter/llm_adapter.py` — использует данные маршрутизатора.
- `docs/total_playbook.md` — описывает сценарии включения.

≈ Фрактальная карта голосов активируется строго по сигналам.
